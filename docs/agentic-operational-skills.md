# Agentic operational skills

This is the on-demand routing map for Matt Pocock's operational skills. Read it only
when choosing or chaining skills across the complete workflow. After routing, load the
selected `SKILL.md`; do not preload the other skill bodies.

Use the smallest skill or sequence that matches the work. The main flow is ordered;
the other groups are entry points for a specific situation.

## 01 Getting started

- `setup-matt-pocock-skills` — configure a repository's tracker and domain-doc
  conventions once, before relying on the rest of this tree.
- `ask-matt` — route an unclear situation to the right Matt Pocock skill.

## 02 The main flow

Use this idea-to-code sequence in order when the starting point is still a product
idea rather than an implementation-ready spec.

- `grill-with-docs` — interview the plan and record decisions.
- `to-spec` — turn the agreed decisions into an implementation spec.
- `to-tickets` — split an approved spec into small, dependency-aware tracer tickets.
- `implement` — build an approved spec test-first.
- `code-review` — review the resulting diff against repository standards and spec.

## 03 Shaping

- `wayfinder` — map a large effort as decisions and resolve its fog before planning.
- `prototype` — answer one design question with disposable code.
- `research` — produce a cited answer from primary sources.

## 04 Upkeep

- `improve-codebase-architecture` — find and prioritize modules worth refactoring.
- `diagnosing-bugs` — diagnose a hard bug from a reproducible failing case.
- `resolving-merge-conflicts` — complete an active merge or rebase hunk by hunk.
- `triage` — classify and verify raw issues into work someone can pick up.
- `wizard` — generate an interactive script for human-only setup steps.

## 05 Productivity skills

- `grill-me` — align on an idea before committing to it.
- `handoff` — package a long session so a fresh agent can continue without archaeology.
- `to-questionnaire` — turn unresolved questions into a document another person fills
  in.
- `teach` — teach a topic across sessions that build on recorded understanding.
- `wait-what` — restate an explanation in plain language.
- `writing-for-agents` — write or revise skills and other documents agents consume.

## 06 Reference skills

- `codebase-design` — use the shared vocabulary for deep modules and clean seams.
- `domain-modeling` — sharpen and record the project's ubiquitous language.
- `grilling` — run the reusable interview process that stress-tests a plan.
- `tdd` — follow the red-green-refactor loop when building behavior.
